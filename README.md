# vsedoma.shop — массовый импорт карточек в каталог Tilda

Маркетплейс [vsedoma.shop](https://vsedoma.shop) на Tilda. Массовое создание карточек проектов делается **импортом CSV в Product Catalog**, а не через публичный API редактора.

## Быстрый процесс

1. **Google Таблица** — одна строка = один проект. Минимум колонка **«название»** (или `Title`). Желательно: описание, цена, категория, HTTPS-ссылки на фото, артикул.
2. **Экспорт или прямая ссылка** — файл CSV или доступ по ссылке (см. ниже).
3. **Конвертация** — скрипт собирает CSV для Tilda (разделитель `;`, UTF-8).
4. **Tilda** — Каталог товаров → **⋮** → **Import (or update) products from CSV**.  
   Для **новых** карточек **не** включайте «Update only existing products».  
   Сопоставьте колонки при первом импорте, если Tilda спросит.

Документация Tilda: [импорт/экспорт каталога](https://help.tilda.cc/online-store/import-export).

## Скрипт

```bash
python3 scripts/sheet_to_tilda_csv.py --input fixtures/vsedoma_sample_sheet.csv -o tilda_products_import.csv
```

Проверить сопоставление колонок без файла:

```bash
python3 scripts/sheet_to_tilda_csv.py --input your_sheet.csv --dry-run
```

### Google Sheets по ID

ID из URL: `https://docs.google.com/spreadsheets/d/THIS_PART/edit#gid=123456`

```bash
python3 scripts/sheet_to_tilda_csv.py --sheet-id "THIS_PART" --gid "123456" -o tilda_products_import.csv
```

Таблица должна быть доступна **«всем, у кого есть ссылка»** (хотя бы просмотр), иначе экспорт вернёт ошибку. Альтернатива: **Файл → Скачать → CSV** и `--input`.

### Значения по умолчанию

Если в таблице нет цены или категории для всех строк:

```bash
python3 scripts/sheet_to_tilda_csv.py --input sheet.csv \
  --default-category "Каркасные дома" \
  --default-price "1490" \
  -o tilda_products_import.csv
```

## Распознаваемые заголовки колонок

| В таблице (примеры) | Поле Tilda |
|---------------------|------------|
| название, проект, Title | Title |
| краткое описание, описание | Description (превью карточки) |
| полное описание, текст, html | Text (попап / детальная карточка) |
| цена | Price |
| категория | Category |
| url фото, фото (несколько URL через пробел/запятую) | Photo (только `https://`) |
| артикул, id | External ID |
| площадь, этажность, материал, … | Characteristics (`Название: значение`) |
| SEO title / SEO descr | SEO title / SEO descr |
| ссылка, url | URL (лендинг проекта, если есть) |

Колонки с именем как в экспорте Tilda (`Category`, `Description`, …) подхватываются автоматически.  
Для своих характеристик: заголовок `Characteristics:Площадь` или `характеристика:Спальни`.

## Рекомендации для vsedoma.shop

- **Первый импорт**: экспортируйте текущий каталог из Tilda (⋮ → Export CSV) — так вы увидите точные названия категорий и формат Characteristics на сайте.
- **Фото**: Tilda принимает **прямые HTTPS-URL**. Удобно хранить файлы в Google Drive / CDN и в таблице держать публичные ссылки.
- **Новые vs обновление**: без колонки `Tilda UID` импорт **создаёт новые** товары. Для обновления существующих экспортируйте каталог с UID и не удаляйте эту колонку.
- **Лимиты**: до 50 MB на файл импорта; на Business — до 50 000 товаров в каталоге.

## Что нужно от вас для автоматизации «под ключ»

Пришлите (можно в следующем сообщении):

1. Ссылку на Google Таблицу (или экспорт CSV) и имя листа.
2. Пример **одной** уже оформленной карточки на vsedoma.shop — сверим поля и категории.
3. Нужны ли варианты товаров (Editions) или одна цена на проект.

После этого можно зафиксировать точный mapping и при необходимости добавить колонки под Tabs (состав проекта, документация и т.д.).
